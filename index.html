⚙ First-time live-room setup (Firebase Spark — no payment card needed)

GitHub Pages is static hosting. Multiplayer needs Firebase Realtime Database. Your friends choose Continue with Google or Continue as guest. Google is required for account-linked report history; guests use Firebase Anonymous Authentication.

  1. At Firebase Console, create a project on the Spark plan.
  2. Add a Web app and copy its Firebase config into FIREBASE_CONFIG at the top of script.js.
  3. In Build → Authentication → Sign-in method, enable Anonymous.
  4. In Build → Realtime Database, create a database and copy its exact databaseURL into your Firebase config. In its Rules tab, paste the complete latest rules from FIREBASE_RULES_STUDENT_HISTORY.json in GitHub and click Publish.
  5. In Authentication → Settings → Authorized domains, add your username.github.io hostname if it is not already listed.
  6. Deploy the three files to your GitHub Pages repository. You do not need a server or Node.js.

Keep the original test code and answer key private: paste it only on the host device. Friends get just the room link. The host must keep the tab open to score submissions automatically. Firebase setup is required only once. Friendly-group app; not a proctored high-security system.
